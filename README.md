# ApkToolMD

An Android APK inspector and reverse-engineering toolkit with a game-mod framework. The repository contains:

- `mod_src/` — native mod and dumper sources (C/C++ with Android makefiles)
- `patches/` — scripts and headers for patching APKs and injecting mods
- `analysis/` — analysis scripts, device dumps, and findings reports (including Cocos/UE4 work)
- `tools/` — helper scripts for analysis, builds, and releases
- `docs/` — project notes and knowledge-transfer documentation
- `ApkToolMD_Reverse_Engineering.ipynb` — a reverse-engineering notebook
- Gradle files (`build.gradle`, `settings.gradle`, `gradle.properties`, `gradlew`) for the Android app
